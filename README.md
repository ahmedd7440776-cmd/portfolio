# Ahmed Mahmoud - Portfolio

Open `index.html` in your browser. No install needed.

## Structure
- index.html : the page content
- css/style.css : all styling and the color palettes (see the :root[data-pal=...] blocks)
- js/main.js : animations, typing effect, palette switcher, project filter
- assets/images/ : put your photo and project screenshots here

## Publish for free
Upload this folder to GitHub Pages or Netlify.
